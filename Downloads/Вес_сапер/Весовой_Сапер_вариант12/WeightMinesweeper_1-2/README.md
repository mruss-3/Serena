# Весовой Сапёр: Сапёр-Разведчик

Лабораторный проект, вариант 12. Игра реализована на Python и Pygame.

## Возможности
- Поле 12×12 с 22 минами весом 1 или 3.
- Перемещение выделения стрелками.
- Проверка клетки клавишей Enter.
- Постановка/снятие флага клавишей F.
- Сохранение текущей игры в JSON клавишей S.
- Запись результатов в CSV и журналирование.
- Ввод имени после победы или поражения прямо в игровом окне.

## Требования
- Python 3.13
- Pygame 2.6.1

## Установка и запуск
Откройте папку проекта в VS Code и выполните в терминале:

```powershell
py -3.13 -m pip install -r requirements.txt
py -3.13 main.py
```

## Управление
- Стрелки — выбрать клетку.
- Enter — проверить выбранную клетку.
- F — поставить или снять флаг.
- S — сохранить игру.
- Esc — выйти.

После победы или поражения в игровом окне появится поле ввода имени. Введите имя и нажмите Enter: результат сохранится в `mines_records.csv`, после чего начнётся новая партия.

## Файлы данных
- `mines_save.json` — сохранённая игра.
- `mines_records.csv` — результаты.
- `minesweeper.log` — журнал событий.
