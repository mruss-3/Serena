# Telegram-бот «Сапёрный Аналитик» (ЛР3)

Бот разработан на библиотеке `aiogram 3` и представляет собой сервис-аналитик для игры «Весовой Сапёр: Сапёр-Разведчик». 
Бот **не является копией игры** в чате — он работает с выгрузками данных, которые создаёт Pygame-приложение.

## 📋 Возможности бота
*   **🏆 Топ игроков** — рейтинг лучших побед по времени (читает `mines_records.csv`).
*   **📊 Моя статистика** — общее количество игр, побед и поражений.
*   **💾 Текущая игра** — читает `mines_save.json` и показывает сохранённое состояние (позиция игрока, открытые клетки, флаги).
*   **🎖 Достижения** — система ачивок (например, «Скороход» за победу < 60 сек).
*   **🔔 Подписка** — уведомления о новых рекордах.
*   **📁 Загрузить CSV** — бот переходит в режим FSM, принимает файл, проверяет формат и обновляет базу рекордов.
