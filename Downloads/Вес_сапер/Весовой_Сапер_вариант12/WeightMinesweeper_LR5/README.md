# Лабораторная работа №5 — «Весовой Сапёр: Сапёр-Разведчик», вариант 12

## Реализовано
- Canvas-отрисовка игрового поля и персонажа;
- игровой цикл `requestAnimationFrame` с фиксированным шагом 16,67 мс и accumulator;
- ввод через массив-флаги клавиш;
- ограниченная видимость вокруг игрока;
- анимация сканирования с изменением радиуса и прозрачности `rgba`;
- индикатор над персонажем;
- HUD с координатами, числом сканирований, флагов и мин;
- реестр сценариев, вызов через кнопки и консоль;
- подключение класса ядра `WeightMinesweeper` из ЛР4 через ES-модуль.

## Структура
`index.html` — страница и Canvas; `css/style.css` — оформление; `js/widget.js` — игровой цикл и связь модулей; `js/input.js` — массив-флаги; `js/renderer.js` — отрисовка; `js/scenarios.js` — сценарии.

## Расположение папок
Обе папки должны находиться рядом:
```text
общая_папка/
├── WeightMinesweeper_LR4/js/WeightMinesweeper.js
└── WeightMinesweeper_LR5/index.html
```

## Запуск на Windows
Откройте терминал VS Code в `общая_папка` (папка, внутри которой лежат оба проекта) и выполните:
```powershell
python -m http.server 8000
```
Откройте `http://localhost:8000/WeightMinesweeper_LR5/`. Если `python` не найден, используйте `py -m http.server 8000`. Не запускайте страницу через `file://`: браузер блокирует ES-модули.

## Управление
- `W`, `A`, `S`, `D` — движение;
- `Enter` — сканирование;
- `F` — флаг;
- `R` — рестарт;
- `Space` — пауза.

## Сценарии
`scanCurrent()` — сканировать клетку; `revealAll()` — показать поле; `togglePause()` — пауза; `restart()` — новая игра. Доступ из консоли:
```js
WeightMinesweeperWidget.scenarios.revealAll()
WeightMinesweeperWidget.scenarios.togglePause()
WeightMinesweeperWidget.scenarios.restart()
```

## Параметры
Поле 8×8; 8 обычных мин весом 1; 4 тяжёлые мины весом 3; шаг симуляции 1000/60 ≈ 16,67 мс; радиус видимости 3,25 размера клетки.

## Модель и представление
Модель — `WeightMinesweeper` из ЛР4 (матрица, мины, движение, сканирование, флаги). Представление — `renderer.js` (Canvas, тайлы, персонаж, туман, эффекты). `widget.js` связывает модель, ввод, сценарии и HUD.
