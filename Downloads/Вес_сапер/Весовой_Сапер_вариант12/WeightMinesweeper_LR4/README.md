# Лабораторная работа №4 — «Весовой Сапёр», вариант 12

## Назначение
Проект содержит независимое от интерфейса математическое ядро игры «Весовой Сапёр», перенесённое с Python на JavaScript ES6+.

## Правила модели
- `0` — безопасная клетка;
- `1` — обычная мина весом 1;
- `3` — тяжёлая мина весом 3;
- при сканировании суммируются веса мин в восьми соседних клетках;
- перемещение выполняется на одну клетку вверх, вниз, влево или вправо;
- попадание на мину завершает игру;
- флаг можно установить на закрытую клетку.

## Структура
- `js/WeightMinesweeper.js` — класс игрового ядра;
- `config/level.json` — конфигурация поля;
- `selftest.js` — автоматические проверки механик;
- `package.json` — настройка ES-модулей.

## Запуск
Требуется Node.js 18 или новее.

```bash
node --version
npm test
```

Также тесты можно запустить напрямую:

```bash
node selftest.js
```

## Основные методы класса
- `movePlayer(deltaRow, deltaCol)` — перемещение игрока;
- `scan(row, col)` — суммирование весов восьми соседних клеток;
- `toggleFlag(row, col)` — установка/снятие флага;
- `getCell(row, col)` — получение состояния клетки;
- `getMineCounts()` — подсчёт мин каждого типа;
- `getPublicState()` — получение открытого состояния игры без скрытых значений мин;
- `WeightMinesweeper.fromJSON(text)` — создание игры из JSON-конфигурации.

## Проверки
`selftest.js` содержит более 20 проверок: генерация поля, распределение мин, подсчёт весов, перемещение, границы, завершение игры, флаги, JSON и обработка некорректных данных.
